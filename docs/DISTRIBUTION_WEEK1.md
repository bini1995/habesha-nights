This kit turns the 50-event catalog into a measurable weekly publishing habit. Nothing here is automated: review the live listing details, then post or send each item manually.

## First 48 hours

1. Recheck the dates and ticket links for the events selected for the first roundup.
2. Publish one NYC roundup and one DMV roundup on Instagram. Put the matching attributed link in the profile or story link sticker.
3. Send the appropriate WhatsApp roundup to a small number of relevant community groups where sharing is welcome.
4. Contact the first five organizers in `ORGANIZER_OUTREACH_PHASE6.csv`. Give each organizer their existing attributed event link, not the general home page.
5. Check the admin scoreboard after 24 and 48 hours. Record views, visitors, ticket clicks, claims, and submissions; do not change product features during this measurement window.

## Organizer outreach

Use the prioritized contacts and event-specific organizer links in `ORGANIZER_OUTREACH_PHASE6.csv`. Start with five organizers, personalize the opening line, and ask only for a correction, claim, or future free submission. Do not sell featured placement during the first contact.

## End-of-week checkpoint

Compare channels on:

- unique visitors
- event views
- outbound ticket clicks
- click-through rate
- event claims or new submissions
- spotlight requests

Keep the channels that create real event actions. Rewrite or pause channels that create impressions without site visits or ticket clicks. The goal is to learn which repeatable distribution loop deserves more effort—not to maximize vanity metrics.
